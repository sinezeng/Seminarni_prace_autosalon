# Seminární práce: Autosalon

Autoři: Yan Xin Zeng, Filip Posíšil, Alan Pavlas

### Popis projektu
Tento projekt obsahuje návrh databáze pro správu autosalonu. Databáze eviduje pobočky, zaměstnance, vozidla, zákazníky, prodeje, servisní záznamy a příplatkovou výbavu.

### Soubory projektu
* **`create.sql`**: Struktura databáze (SQL příkazy pro vytvoření tabulek).
* **`insert.sql`**: Ukázková data pro naplnění databáze.
* **`queries.sql`**: Soubor obsahující 15 požadovaných SQL dotazů.
